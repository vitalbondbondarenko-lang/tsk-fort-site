# ТСК ФОРТ — корпоративный сайт

[Публичная версия](https://vitalbondbondarenko-lang.github.io/tsk-fort-site/)

20 самостоятельных страниц: генподряд, капитальный ремонт, проектирование, фасады, кровли, инженерия, архитектурные концепции, компания, организация работ, документы, контакты и журнал. Каждая страница получает готовый HTML, индивидуальные метаданные и прямой адрес на GitHub Pages.

## Работа с проектом

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm preview
```

Базовый путь: `/tsk-fort-site/`. Страницы и тексты — `src/siteData.js` и `src/Site.jsx`; визуальная система — `src/site.css`. Статическая генерация — `scripts/prerender.mjs`.

Проверка: `QA_URL=http://127.0.0.1:4173/tsk-fort-site/ pnpm run qa`. Сценарий использует локальный Chrome и Playwright из окружения Codex. Нужный порт выводится командой preview. Снимки и результаты проверки сохраняются в `qa/` и не публикуются.

## Архитектурное 3D

Три оригинальные сцены созданы в Blender: многоквартирный дом, школа и медицинский комплекс. Скрипт воспроизведения — `scripts/build_models.py`. GLB и рендеры для сайта — `public/models/`. Исходники `.blend` сохраняются локально в `source-assets/models/` и исключены из репозитория.

Интерактивный просмотрщик на React Three Fiber подгружается отдельно. Поддерживает вращение, паузу, масштаб, конструктивный режим, ракурс сверху и клавиатуру. При недоступном WebGL сохраняется архитектурный рендер. Сцена приостанавливается вне экрана; автоматическое вращение выключено при reduced motion.

Это демонстрационные архитектурные концепции, а не перечень реализованных ТСК ФОРТ заказов. Контакты и реквизиты сверены с материалами компании. Тексты услуг оригинальные; показатели и достижения сторонних компаний не используются.

## Обращения и публикация

Форма подготавливает письмо в почтовой программе пользователя. Она не отправляет заявку автоматически и не имитирует успешную доставку. Файлы можно приложить к письму перед отправкой.

Публикация запускается push в `main` через `.github/workflows/deploy-pages.yml`. После успешного workflow проверяются публичные страницы и модельные файлы.

Шрифты Manrope и Onest размещены локально; лицензии OFL находятся в `public/fonts/`.
