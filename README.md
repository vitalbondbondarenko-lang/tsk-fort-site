# ТСК ФОРТ — корпоративный сайт

Статический сайт: готовый HTML для каждой страницы, локальные стили, скрипты, изображения и шрифты. На обычном хостинге не нужны Node.js, база данных или сервер React. Исходники и локальная сборка сами по себе не означают публикацию.

Тексты и маршруты — `src/siteData.js`, страницы — `src/Site.jsx`, стили — `src/site.css`. Настройки размещения сосредоточены в `src/siteConfig.js`; генерация HTML — `scripts/prerender.mjs`.

## Локальная работа

```bash
pnpm install --frozen-lockfile
pnpm dev
```

По умолчанию dev и `pnpm build` используют исторический путь GitHub Pages `/tsk-fort-site/`. Для разработки в корне домена:

```bash
SITE_BASE=/ SITE_URL= pnpm dev
```

## Пакет для обычного хостинга

```bash
pnpm build:hosting
```

Результат — каталог `dist-hosting/`, который не зависит от `dist/`. В него входят готовые страницы, общие ресурсы, `404.html`, `robots.txt`, а также перенаправления прежних адресов. Для просмотра через Vite:

```bash
SITE_BASE=/ SITE_URL= pnpm exec vite preview --outDir dist-hosting --host 127.0.0.1
```

Загружать нужно **содержимое** `dist-hosting/` в корневую папку выбранного сайта: например, `public_html/` или `www/` — точное имя показывает панель хостинга. Сохранить структуру каталогов и скрытый файл `.htaccess`. Не загружать `src/`, `node_modules/`, `qa/`, исходники документов и рабочие материалы.

Пока домен не указан, в пакете намеренно отсутствуют canonical, `og:url`, абсолютные URL организации и `sitemap.xml`. В `robots.txt` нет ссылки на GitHub. Перед окончательной публикацией после выбора домена следует пересобрать пакет:

```bash
SITE_URL=https://example.ru/ pnpm build:hosting
```

`example.ru` — пример, его нужно заменить согласованным адресом. Сборка добавит метаданные и sitemap для указанного адреса; HTTPS и привязка домена настраиваются на хостинге отдельно. Сборка не меняет DNS и не публикует файлы.

`.htaccess` задаёт главную `index.html`, собственную страницу 404 и HTTP 301 для прежних маршрутов на Apache с разрешёнными соответствующими директивами. На nginx или хостинге без `.htaccess` остаются статические страницы перенаправления через HTML; они возвращают HTTP 200 до перехода. Для настоящих 301 и собственной страницы 404 на таком сервере нужны настройки панели или сервера. Обычные разделы открываются напрямую из собственных `index.html`; единый SPA rewrite не требуется.

После загрузки проверяются точный публичный адрес без авторизации, HTTPS, главная и прямой вход в раздел, ресурсы, телефон/почта, перенаправления и HTTP 404 на неизвестном пути. Проверка через один компьютер и сетевой маршрут не доказывает доступность у всех посетителей.

## Исторический GitHub Pages

Адрес прежней публикации: <https://vitalbondbondarenko-lang.github.io/tsk-fort-site/>. Его публичное содержимое меняется только после отдельной публикации.

```bash
pnpm build
pnpm preview
```

`dist/` использует `/tsk-fort-site/` и адрес GitHub Pages. Workflow `.github/workflows/deploy-pages.yml` явно задаёт эти параметры; push в `main` запускает публикацию GitHub Pages. Локальные изменения и сборка не запускают workflow.

Проверки и снимки сохраняются в `qa/` и не публикуются. Шрифты Manrope и Onest размещены локально; лицензии OFL — в `public/fonts/`.

## Проверка выпуска

В актуальной редакции 17 содержательных страниц и 9 перенаправлений старых адресов. Фотографии в карточках — исходное состояние из обследований, а не результат ремонта. Состав участия описан отдельно для каждого объекта.

Для локальной проверки архива запустите `node scripts/serve-static.mjs` после `pnpm build:hosting`. Адрес — `http://127.0.0.1:4180/`. В другом терминале выполните `pnpm qa`. Сценарий проверяет все маршруты на ширинах 320, 390, 768 и 1440 px, навигацию, изображения, перенаправления, контакты, 404 и страницы без JavaScript. Требуется Playwright; путь к модулю и Chrome можно передать через `QA_PLAYWRIGHT_MODULE` и `QA_CHROME`.

В публичную сборку попадает явный список ресурсов из `vite.config.js`: логотип, фотографии объектов, Manrope, favicon и текстовая карточка компании. Старые 3D-модели, иллюстрации, внутренние отчёты и тестовые артефакты в пакет не входят.
