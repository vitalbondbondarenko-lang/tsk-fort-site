# ТСК ФОРТ — дизайн-прототип сайта

Адаптивный прототип главной страницы с акцентом на генеральный подряд и проектирование.

Публичная версия: https://vitalbondbondarenko-lang.github.io/tsk-fort-site/

## Запуск

```bash
pnpm install
pnpm dev
```

Локальный адрес: `http://127.0.0.1:4173/`.

## Важно перед публикацией

- заменить сгенерированную hero-иллюстрацию реальной фотографией с подтверждёнными правами;
- подтвердить контакты, географию работ, состав проектных услуг и перечень инженерных работ;
- наполнить раздел объектов только подтверждёнными кейсами;
- добавить актуальные СРО, лицензии, сведения о специалистах и юридические документы;
- подключить фактическую отправку формы и обработку персональных данных.

Hero-изображение создано встроенным инструментом генерации изображений и используется только как визуальная концепция. Оптимизированная версия находится в `public/assets/hero-construction-concept.jpg`, исходный PNG — в `source-assets/`.
